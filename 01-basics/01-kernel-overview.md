# 커널(Kernel)이란?

커널은 운영체제의 핵심 부분으로 CPU, 메모리, 입출력 장치와 같은 시스템 자원을 관리하는 소프트웨어다
운영체제의 가장 기본적인 기능을 담당하고 프로그램이 하드웨어 자원을 사용할 수 있도록 필요한 서비스를 제공한다 그리고 여러 프로그램이 실행될 때 시스템 자원을 분배하고 관리하는 역할을 한다

## 커널의 주요 역할

커널은 CPU, 메모리, 입출력 장치와 같은 시스템 자원을 관리하며 프로그램이 이러한 자원을 사용할 수 있도록 여러 기능을 제공한다

### 프로세스 관리

여러 프로세스가 실행될 때 어떤 프로세스가 CPU를 사용할지, 얼마나 사용할지를 결정하는 역할이다
프로세스의 생성과 종료를 처리하고 실행 상태를 관리하고 여러 프로세스가 CPU를 나누어 사용할 수 있게 한다

### 메모리 관리

프로세스가 실행되는 데 필요한 메모리를 관리하는 역할이다
각 프로세스에 가상 주소 공간을 제공하고 필요한 메모리를 할당하며 다른 프로세스의 메모리에 허가 없이 접근하지 못하게 보호한다

### 장치 관리

키보드, 마우스, 디스크와 같은 하드웨어 장치를 관리하는 역할이다
프로그램이 하드웨어를 사용하려고 할 때 장치 드라이버를 통해 장치와 데이터를 주고받을 수 있게 한다

### 파일 시스템 관리

파일과 디렉터리를 생성하거나 읽고 쓰는 등의 작업을 관리하는 역할이다
리눅스에서는 vfs를 통해 ext4, xfs처럼 서로 다른 파일 시스템을 동일한 방식으로 사용할 수 있도록 한다

### 시스템 콜 처리

사용자 프로그램이 커널의 기능을 요청할 때 그 요청을 처리하는 역할이다
프로그램이 read()를 호출하면 시스템 콜을 통해 커널에 파일 읽기를 요청하고 커널은 그 작업을 처리한 뒤 결과를 반환한다

## 자원의 추상화

자원의 추상화는 하드웨어의 복잡한 내부 구조를 감추고 프로그램이 자원을 쉽게 사용할 수 있도록 제공한다

프로그램이 하드웨어를 직접 다루려면 내부 구조나 동작 방식을 알아야 하는데 커널은 이 부분을 관리해서 자원을 쉽게 사용하게 해준다

### 파일의 추상화

커널이 파일 시스템을 통해 데이터가 저장된 위치를 관리하기 때문에 프로그램은 실제 저장 위치를 몰라도 파일을 사용할 수 있다

### 메모리의 추상화

프로그램은 실제 물리 메모리 주소 대신 가상 주소를 사용하고 프로세스에 제공되는 가상 주소의 범위를 가상 주소 공간이라고 한다

가상 주소를 사용해서 프로그램은 데이터가 실제 물리 메모리에 어디에 저장되어 있는지 직접 관리할 필요가 없다 주소 변환은 커널이 관리하는 페이지 테이블을 이용해 CPU가 수행한다
