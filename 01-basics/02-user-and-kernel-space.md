# 사용자 공간과 커널 공간

리눅스에서는 일반 프로그램이 사용하는 사용자 공간과 커널이 사용하는 커널 공간이 있다

공간을 나누는 이유는 일반 프로그램이 커널의 데이터에 직접 접근하거나 잘못 수정하는 것을 막기 위함이다

### 사용자 공간 (User Space)

일반 프로그램이 실행되는 공간이고 프로그램의 코드나 데이터 등이 저장되는 영역이다

프로그램은 자신에게 허용된 메모리에만 접근할 수 있고 커널 공간에는 직접 접근할 수 없다
그리고 프로세스마다 사용하는 가상 주소 공간이 구분되어 있어서 서로 다른 프로세스에서 같은 가상 주소를 사용해도 실제로는 다른 물리 메모리를 가리킬 수 있다

### 커널 공간 (Kernel Space)

커널의 코드와 데이터, 장치 드라이버 등이 저장되는 영역이다

커널이 CPU, 메모리, 장치와 같은 시스템 자원을 관리하는 데 필요한 정보들이 저장되고 일반 프로그램이 직접 접근하지 못하게 보호된다

## 사용자 모드와 커널 모드

사용자 공간과 커널 공간은 메모리 영역을 구분하는 개념이고
사용자 모드와 커널 모드는 CPU의 실행 권한을 구분하는 개념이다

### 사용자 모드 (User Mode)

일반 프로그램이 실행되는 모드고 실행 권한이 제한되어 있다
커널 메모리에 직접 접근하거나 하드웨어 제어에 필요한 일부 명령을 실행할 수 없다

### 커널 모드 (Kernel Mode)

커널 코드가 실행되는 모드고 시스템 자원을 관리하거나 하드웨어를 제어하는 데 필요한 명령을 실행할 수 있다

일반 프로그램이 커널의 기능을 사용하려면 시스템 콜을 통해 작업을 요청해야 한다
프로그램이 read()를 호출하면 CPU가 커널 모드로 전환되고 커널이 파일 읽기 작업을 처리한 뒤 사용자 모드로 돌아온다
