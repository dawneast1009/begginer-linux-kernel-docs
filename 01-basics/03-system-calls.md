# 시스템 콜(System Call)이란?

시스템 콜은 사용자 프로그램이 커널에 작업을 요청할 때 사용하는 인터페이스다

일반 프로그램은 커널이 관리하는 자원을 마음대로 조작할 수 없어서 파일 읽기와 쓰기, 프로세스 생성 같은 작업을 시스템 콜을 통해 요청한다

## 라이브러리를 통한 시스템 콜 사용

프로그램은 보통 라이브러리에서 제공하는 함수를 통해 시스템 콜을 사용한다

라이브러리는 프로그램에서 사용할 수 있는 함수들을 모아둔 것이고 시스템 콜을 호출하는 데 필요한 정보를 준비하고 결과를 전달하는 역할도 한다

파일을 읽을 때 사용하는 read()는 파일 디스크립터, 버퍼, 크기를 인자로 받는다

## 시스템콜 동작

read()를 보면

1. 프로그램이 read()를 호출하고 파일 디스크립터, 버퍼, 크기를 전달한다
2. 라이브러리가 시스템 콜에 필요한 정보를 준비한다
3. CPU가 커널 모드로 전환되고 커널이 요청을 확인한다
4. 커널이 파일 읽기 작업을 처리하고 데이터를 버퍼에 저장한다
5. 처리 결과를 반환하고 사용자 모드로 돌아온다

## 시스템콜 반환값

시스템 콜을 사용한 뒤에 반환값으로 작업이 어떻게 처리되었는지 확인할 수 있다

read()는 읽은 바이트 수를 반환한다

- 양수 : 읽은 바이트 수
- 0 : 일반 파일에서 파일의 끝에 도달
- -1 : 오류가 발생

## 모든 함수가 시스템콜 사용?

프로그램에서 함수를 호출한다고 항상 시스템 콜을 사용하는건 아니다
이미 접근할 수 있는 메모리에서 데이터를 처리하거나 계산하는 작업은 시스템 콜 없이 진행가능하다

strlen()으로 예를들면 문자열의 길이를 구하는 함수이기에 문자열 끝의 널 문자를 제외한 바이트 수를 계산한다

이런 계산에는 시스템 콜이 필요하지 않아서 시스템콜을 사용하지 않는다
