# 가상 주소, 물리 주소, 페이지 테이블

## 가상 주소, 물리 주소

가상 주소는 프로그램이 메모리에 접근할 때 사용하는 주소고 물리 주소는 실제 물리 메모리의 위치를 나타내는 주소다

프로세스마다 사용하는 가상 주소 공간이 구분되어 있어서 서로 다른 프로세스가 같은 가상 주소를 사용해도 각각 다른 물리 메모리를 가리킬 수 있다

## 페이지와 페이지 프레임

가상 주소 공간을 일정한 크기로 나눈 단위를 페이지라고 한다
물리 메모리에서 페이지 하나가 들어갈 수 있는 같은 크기의 공간을 페이지 프레임이라고 한다

## 페이지 테이블

페이지 테이블은 어떤 가상 페이지가 어느 물리 페이지 프레임에 연결되는지 기록하는 자료구조다
각 항목에는 연결된 프레임 번호와 해당 메모리에 쓰기가 가능한지 같은 접근 권한도 들어 있다

### 페이지 번호와 오프셋

가상 주소는 페이지 번호와 오프셋으로 나눠서 볼 수 있다

- 페이지 번호는 어느 가상 페이지에 접근할지 나타낸다
- 오프셋은 그 페이지의 시작점에서 얼마나 떨어진 곳에 접근할지 나타낸다

### 주소 변환 예시

워드(word)는 CPU가 데이터를 다룰 때 쓰는 크기 단위다
아래 그림에서는 메모리 한 칸을 1워드로 보고 네 칸을 한 페이지로 묶었다

![](https://velog.velcdn.com/images/dawneast/post/c6971063-3c2d-4151-8173-26025697c4b4/image.png)

가상 주소 5에 있는 데이터를 읽으면

1. 가상 주소 5는 페이지 1의 시작 주소인 4에서 1워드 떨어져 있다 그래서 (페이지 번호, 오프셋)으로 적으면 (1, 1)
2. 페이지 테이블에서 페이지 번호 1을 찾으면 프레임 번호 2가 나온다. 오프셋은 1 그대로라서 (프레임 번호, 오프셋)은 (2, 1)
3. 프레임 2의 시작 주소는 8 여기서 오프셋 1만큼 떨어진 물리 주소 9에 있는 j를 읽음

이렇게 주소를 변환하면 페이지 번호 1은 프레임 번호 2로 바뀌고 오프셋 1은 그대로다
